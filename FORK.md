# About this fork

`roosmsg/hex` is a fork of [anomalyco/hex](https://github.com/anomalyco/hex).
It adds a way for Hex to hand a dictation to another app on the same PC, such
as [Restage](https://github.com/roosmsg/Restage), instead of only pasting it.

- Based on `anomalyco/hex` branch `dev` at `53164934` (7 November 2026, Hex 3.3.0).
- The work is on branch `labs-send-to-endpoint`, which is also this fork's
  default branch (GitHub only offers to run workflows from the default branch).

## What changed

### Labs › Send to endpoint (Windows)

A new lab in Settings › Labs, in the Output group. It is off by default.

While it is on and a URL is set, every finished dictation is sent as JSON to
that URL with an HTTP POST. This happens after Hex's own Output steps
(corrections, transformations). The dictation is no longer pasted, unless
*Also paste the dictation* is on.

| Setting | `hex settings` key | Default |
| --- | --- | --- |
| On or off | `labs.send_to_endpoint` | off |
| Endpoint URL | `endpoint.url` | none (nothing is sent) |
| Bearer token | `endpoint.token` | none |
| JSON body | `endpoint.body` | `{"text": "{text}"}` |
| Also paste the dictation | `endpoint.paste` | off |

- `{text}` in the body stands for the dictation, escaped for a JSON string.
- The card shows these fields while the lab is on. Typing is saved as soon as
  it pauses.
- From a shell: `hex labs on send-to-endpoint`, then
  `hex settings set endpoint.url http://127.0.0.1:1234/command`, and so on.

How it behaves:

- **Loopback stays local.** A `localhost` or `127.0.0.1` URL never leaves the
  PC, redirects included. Other hosts go through the system proxy.
- **The token is never printed.** `hex settings get endpoint.token` and
  `hex settings list` show only `(set)`.
- **Logs** name the host and the HTTP status, never the body or the token.
- **A failed send is not silent.** With pasting off, the dictation fails and
  the HUD says so. Paste last dictation still has the text either way.
- **Printed dictations** (`hex dictation stop --print`) are never sent.
- The request times out after 10 seconds.

It is called "endpoint" rather than "local API" because Hex already has a
`local_api` module: its own server.

### Hex on GitHub instead of Quit Hex (Windows)

The window's bottom-left row now opens https://github.com/anomalyco/hex.
Quitting stays in the tray menu. Linux keeps Quit Hex in the window, because
it has no tray. macOS is unchanged.

### Housekeeping

- Hex fails any source file over 1,500 non-test lines. To stay under that,
  some code moved verbatim into new files: `labs/cli.rs`,
  `control/settings/gate.rs`, `desktop/i18n/locale.rs` and `rune_ui/drafts.rs`.
- New interface text is translated into every language Hex has.
- The Windows Labs golden image was regenerated by the Check Linux workflow.
- `docs/features/labs.md`, `docs/windows.md` and `AGENTS.md` describe the
  changes.

## Using it with Restage

Restage's local API takes spoken commands at `POST /command`.

1. Run `restage api`, or open `%LOCALAPPDATA%\Restage\local-api.json`, to find
   the port and the token.
2. Set the endpoint URL to `http://127.0.0.1:<port>/command` and the bearer
   token to that token.
3. Leave the body as it is: `{"text": "{text}"}` is what Restage expects.
4. Dictate "open research", and Restage starts that workspace.

The port and token change every time Restage starts, so for now they have to
be updated after a restart.

## Building and installing

Hex's Windows build needs MSVC, CMake and the Vulkan SDK, so it is easiest
on GitHub Actions:

- **Test builds** (`test-builds.yml`, run it by hand from the Actions tab) makes
  `hex-setup-<version>-windows-x64.exe`, in the run's `windows-installers`
  artifact. The installer is unsigned: at the SmartScreen warning choose
  *More info*, then *Run anyway*. Test builds never update themselves.
- **Check Windows** (`check-windows.yml`) runs fmt, clippy, the tests and a
  release build.
- **Check Linux** (`check-linux.yml`) checks the UI goldens. Its `nix` job
  fails on this fork because it lacks Anomaly's FlakeHub cache token; that
  failure is unrelated to the code.
