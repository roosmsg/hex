# About this fork

`roosmsg/hex` is a fork of [anomalyco/hex](https://github.com/anomalyco/hex).
It adds a way for Hex to hand a dictation to another app on the same PC, such
as [Restage](https://github.com/roosmsg/Restage), instead of only pasting it.

- Up to date with `anomalyco/hex` branch `dev` at `84462c9f` (7 November
  2026, Hex 3.3.0).

## Branches

- **`dev`** mirrors upstream's `dev` and carries nothing of this fork's.
  Bring it up to date with *Sync fork* on GitHub, or
  `git push origin upstream/dev:dev`.
- **`labs-send-to-endpoint`** holds this fork's additions on top of upstream.
  New upstream commits come in by merging `dev` into it (merges, not
  rebases, since the branch is public). It is the fork's default branch,
  because GitHub only offers to run workflows from there, and every fork
  release is built from it, so a release always has upstream's latest
  merged changes plus the fork's own.

## What changed

### Labs › Send to endpoint (Windows)

A new lab in Settings › Labs, in the Output group. It is off by default.

While it is on, Hex looks at how each finished dictation starts. If it starts
with an endpoint's **name**, the rest of the dictation is sent as JSON to
that endpoint with an HTTP POST, after Hex's own Output steps (corrections,
transformations):

- "Restage, open portfolio" sends `open portfolio` to the endpoint named
  *Restage*.
- A dictation that starts with no endpoint's name pastes as usual, so normal
  dictation keeps working with the lab on.

Each endpoint has these fields; the card has *Add endpoint* and *Remove*:

| Field | Meaning |
| --- | --- |
| Name | Said first, it sends the rest here, such as Restage; without one the endpoint receives nothing |
| Endpoint URL | The http(s) URL that takes the POST |
| Bearer token | Sent as `Authorization: Bearer …`, if set |
| JSON body | Default `{"text": "{text}"}`; `{text}` is the words, escaped for JSON |
| Also paste the dictation | Paste what was sent too; off by default |

- A name matches however speech writes it: "Re-stage", "re stage" and
  "Restage," all count. The longest matching name wins.
- From a shell: `hex labs on send-to-endpoint`, and the list as JSON with
  `hex settings get endpoints` and `hex settings set endpoints '[…]'`. Tokens
  show as `(set)`; setting the list back with `(set)` keeps the saved token.
- At most 10 endpoints, and no two names that sound the same.

How it behaves:

- **Loopback stays local.** A `localhost` or `127.0.0.1` URL never leaves the
  PC, redirects included. Other hosts go through the system proxy.
- **Logs** name the endpoint, its host and the HTTP status, never the body or
  the token.
- **A failed send is not silent.** With pasting off, the dictation fails and
  the HUD says so. Paste last dictation still has the text either way.
- **Printed dictations** (`hex dictation stop --print`) are never sent.
- The request times out after 10 seconds.
- A settings file from the first, single-endpoint version keeps its endpoint:
  it becomes the first in the list, without a name; give it one to use it.

It is called "endpoint" rather than "local API" because Hex already has a
`local_api` module: its own server.

### Hex on GitHub instead of Quit Hex (Windows)

The window's bottom-left row now opens https://github.com/anomalyco/hex.
Quitting stays in the tray menu. Linux keeps Quit Hex in the window, because
it has no tray. macOS is unchanged.

### Housekeeping

- Hex fails any source file over 1,500 non-test lines. To stay under that,
  some code moved verbatim into new files: `labs/cli.rs`,
  `control/settings/gate.rs`, `desktop/i18n/locale.rs` and `rune_ui/drafts.rs`.
- New interface text is translated into every language Hex has.
- The Windows Labs golden image was regenerated by the Check Linux workflow.
- `docs/features/labs.md`, `docs/windows.md` and `AGENTS.md` describe the
  changes.

## Using it with Restage

Restage's local API takes spoken commands at `POST /command`.

1. In Restage, open Settings › *Connect apps* and copy the command URL and
   the token.
2. Name the endpoint `Restage`, paste the URL and the token, and leave the
   body as it is: `{"text": "{text}"}` is what Restage expects.
3. Dictate "Restage, open portfolio", and Restage starts that workspace.

The URL and token stay the same when Restage restarts.

## Building and installing

Hex's Windows build needs MSVC, CMake and the Vulkan SDK, so it is easiest
on GitHub Actions:

- **Fork release** (`fork-release.yml`): `gh workflow run fork-release.yml
  -f number=1` (or *Run workflow* in the Actions tab) builds the Windows
  installers from `labs-send-to-endpoint` and publishes them as release
  `v<version>-fork.<number>`. Raise the number for each release of the same
  Hex version.
- **Test builds** (`test-builds.yml`, run it by hand from the Actions tab) makes
  `hex-setup-<version>-windows-x64.exe`, in the run's `windows-installers`
  artifact. The installer is unsigned: at the SmartScreen warning choose
  *More info*, then *Run anyway*. Test builds never update themselves.
- **Check Windows** (`check-windows.yml`) runs fmt, clippy, the tests and a
  release build.
- **Check Linux** (`check-linux.yml`) checks the UI goldens. Its `nix` job
  fails on this fork because it lacks Anomaly's FlakeHub cache token; that
  failure is unrelated to the code.
